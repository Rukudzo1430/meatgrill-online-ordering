# meatgrill online ordering
online food ordering system for meatgrill,built with python and web technologies
Meatgrill Online Ordering System

About the Project

Meatgrill Online Ordering System is a web-based food ordering platform designed to make ordering meals convenient for customers.

The project aims to provide an easy way to browse the menu, add meals to a shopping cart, place orders, and choose delivery or collection.

Planned Features

- Browse food menu and prices
- Add and remove items from the shopping cart
- Calculate order totals automatically
- Customer contact and delivery details
- Place and manage orders
- Admin dashboard for restaurant staff
- Order status updates
- Sales reports and summaries
- Mobile-friendly design

Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

Project Status

Currently in development.

Purpose

This project is being developed as a portfolio project and as a potential online ordering solution for Meatgrill.
